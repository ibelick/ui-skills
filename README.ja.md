# UI Skills

[English](./README.md) | [简体中文](./README.zh-CN.md)

![UI Skills](./public/UI-OG.webp)

デザインエンジニア向けのスキル集

詳しくは [ui-skills.com](http://ui-skills.com/) をご覧ください。

`npx ui-skills start` を実行すると、タスクに適した UI スキルセットへエージェントを誘導できます。

## CLI

```bash
npx ui-skills
npx ui-skills start
npx ui-skills categories
npx ui-skills list --category motion
npx ui-skills get baseline-ui
```
